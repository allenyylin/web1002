中級進階

嘉明湖高山隕石坑探索 4天3夜

每日詳細行程規劃：

Day 1: 池上集合 → 向陽國家森林遊樂區 → 向陽山屋。

Day 2: 向陽山屋 → 稜線步道 → 嘉明湖避難山屋。

Day 3: 嘉明湖避難山屋 → 三叉山 → 嘉明湖(天使的眼淚)環湖攝影 → 回程至向陽山屋。

Day 4: 向陽山屋 → 輕鬆下山返抵向陽遊樂區 → 池上享用在地名產與慶功解散。
